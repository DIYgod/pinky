# DIYgod's Homebrew tap

```sh
brew install --cask diygod/tap/pinky
```

| Cask | |
| --- | --- |
| [`pinky`](Casks/pinky.rb) | [Pinky](https://github.com/DIYgod/pinky-releases): let AI agents use your phone, with you in the loop. Also installs the `pinky` command (`pinky mcp`). |

Pinky updates itself, so `brew upgrade` leaves it alone unless you pass `--greedy`. Its release workflow updates the cask with every release.
