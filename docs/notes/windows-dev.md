# Windows local development build

Run `sh scripts/windows-dev.sh` from Git Bash (or `make windows-dev` when Make is installed). This builds `build/pinky/windows-amd64/Pinky.exe` and its local installer, prepares the pinned iOS developer disk image in Pinky's per-user data directory, and restores the four FFmpeg 9 DLLs beside the executable after MyGo recreates the build directory. Re-run the same command after pulling code or rebuilding; the image and FFmpeg archive are cached and verified by SHA-256. It does not start or stop the running application.

The script uses the iOS driver's pinned developer disk image download and checks the stored files and source revision before reusing them. A download does not touch a phone; Pinky mounts the image as needed when the phone connects. The image used on the Windows test machine was the `27A5228h` mirror; hao's iPhone subsequently mounted it and opened its WebDriverAgent stream. Older iOS releases still require their own compatible developer image or supported driver path.

For this local development build only, the script downloads BtbN's pinned GPL FFmpeg 9 shared archive to `build/ffmpeg-windows-dev/ffmpeg.zip`. Supply an already downloaded archive using `PINKY_WINDOWS_FFMPEG_ZIP=<absolute Windows path> sh scripts/windows-dev.sh`; its digest must match the pin. `scripts/dist.sh` builds and packages Pinky's separate LGPL FFmpeg libraries for releases. The `latest` development archive URL may change: a different digest is rejected, and the development archive pin needs updating from a verified build before a fresh download can work again. Do not distribute the BtbN DLLs as part of Pinky's release artifacts.

Observed on 2026-11-13: the Windows build produced Pinky.exe and the installer, and the helper restored `avcodec-63.dll`, `avutil-61.dll`, `swscale-10.dll`, and `swresample-7.dll` after MyGo recreated the output folder. The iOS developer image passed all stored-file digest checks. On hao's iPhone, the mirror opened and encoded at 620x1344, 15 fps. A separate intermittent WebDriverAgent MJPEG outage had refused port 9100 for several minutes; the device going offline and reopening restored the stream. The asset setup does not fix a live WDA or Wi-Fi outage. Recent Wi-Fi screen reads also took 8–15 seconds; if the live mirror goes blank while the DLLs and image are present, inspect the current gateway log and connection state.
