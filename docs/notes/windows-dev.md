# Windows local development build

Run `sh scripts/windows-dev.sh` from Git Bash (or `make windows-dev` when Make is installed). The script builds `build/pinky/windows-amd64/Pinky.exe` (and its installer where NSIS is installed) with MyGo, staging the LGPL FFmpeg 9 DLLs from `build/ffmpeg-windows/bin` through MyGo's resources so the build carries them beside `Pinky.exe`, then removing the temporary resources. Re-run the same command after pulling code or rebuilding. It does not start or stop the running application.

The script reads its FFmpeg libraries from `build/ffmpeg-windows/bin`; make them with `scripts/ffmpeg.sh build/ffmpeg-windows windows-amd64` (in a Docker container). Without that folder the build still runs, but the mirror then needs FFmpeg at run time: put the DLLs next to `Pinky.exe`, or set `PINKY_FFMPEG_DIR` to a folder of FFmpeg 9 libraries (both are in the README's Windows section). The script downloads nothing and does not prepare the iOS developer disk image; **Add phone › iPhone** offers the developer disk image, so the script only builds and carries the DLLs. Released packages are made by `scripts/dist.sh` and the release workflow instead, with their own LGPL FFmpeg.

Prior observations (2026-11-13, from the earlier script, which also downloaded the pinned developer disk image and a development FFmpeg archive that the current script no longer downloads): the Windows build produced Pinky.exe and the installer, and the helper restored `avcodec-63.dll`, `avutil-61.dll`, `swscale-10.dll`, and `swresample-7.dll` after MyGo recreated the output folder. The iOS developer image passed all stored-file digest checks. On hao's iPhone, the mirror opened and encoded at 620x1344, 15 fps. A separate intermittent WebDriverAgent MJPEG outage had refused port 9100 for several minutes; the device going offline and reopening restored the stream. The asset setup does not fix a live WDA or Wi-Fi outage. Recent Wi-Fi screen reads also took 8–15 seconds; if the live mirror goes blank while the DLLs and image are present, inspect the current gateway log and connection state.
